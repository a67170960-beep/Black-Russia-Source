# Локальный тест собственного CRMP-проекта в Termux

## Что уже есть

Этот репозиторий содержит Android-клиент/лаунчер. Серверной части Black Russia здесь нет. Папка openmp-server должна содержать только оригинальный сервер собственного проекта и не использовать закрытые ресурсы или серверные исходники Black Russia.

Важно: текущий Android-клиент отправляет модифицированный SA-MP/RakNet handshake (NETGAME_VERSION 4057, AUTH_BS и собственные RPC). Поэтому обычный open.mp-сервер нельзя считать совместимым автоматически. Сначала нужно проверить handshake и базовый join.

## Termux на том же телефоне

В Termux:

    pkg update -y && pkg install -y git tmux proot-distro

Установка Debian через proot нужна, если серверный бинарник собран под glibc Linux:

    proot-distro install debian
    proot-distro login debian
    apt update
    apt install -y ca-certificates git tmux

В Debian создай отдельную папку сервера, положи туда совместимый серверный бинарник и config.json, затем:

    mkdir -p ~/crmp-server
    cd ~/crmp-server
    chmod +x ./omp-server
    tmux new -s crmp './omp-server'

Отключиться от tmux без остановки сервера: Ctrl-B, затем D. Вернуться:

    tmux attach -t crmp

Для локального теста сервер должен слушать 127.0.0.1:7777. Проверка порта:

    ss -lun | grep 7777

## Подключение клиента

Не меняй адрес клиента до проверки совместимости. После появления сервера, который понимает этот клиентский протокол, адрес в Jni source/jni/clientlogic/CNetwork.cpp для локального теста будет выглядеть так:

    CSetServer::create("127.0.0.1", 128, 9, 7777, false)

Здесь 128 — сумма октетов IP (127+0+0+1), 9 — длина строки IP, 7777 — UDP-порт. Обе записи серверов нужно настроить одинаково или оставить одну запись.

После изменения JNI исходники собираются через Android NDK (ndk-build). Получившийся libsamp.so заменяет файл в app/jniLibs/armeabi-v7a/, затем APK собирается Android Studio или CI. Собирать Android APK в Termux можно, но это отдельная тяжёлая настройка SDK/NDK; для первого теста проще использовать Android Studio/CI.

## Ограничения

- Это локальный тест: проброс портов и публичный IP не нужны.
- Запущенный open.mp-MVP сам по себе не делает текущий Black Russia-клиент совместимым.
- Для полноценного соединения нужны серверные обработчики handshake, авторизации, RPC и синхронизации, соответствующие этому клиенту.
- Не добавляй в сервер закрытые игровые ресурсы, ключи, базу или код, на использование которых нет прав.
