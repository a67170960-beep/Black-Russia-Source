# Own CRMP MVP server

Это оригинальный тестовый режим для open.mp. Он не является серверной частью Black Russia и не содержит закрытых игровых ресурсов.

## Что есть сейчас

- локальная регистрация и вход в памяти процесса;
- стартовый спавн;
- чат;
- команды /help, /stats, /spawn и /save;
- локальная конфигурация 127.0.0.1:7777.

Пароли и деньги пока не переживают перезапуск сервера. Следующим отдельным этапом можно добавить SQLite и серверную админку.

## Сборка

1. Установи open.mp server и Pawn compiler под свою архитектуру.
2. Скомпилируй gamemodes/crmp_mvp.pwn.
3. Положи полученный gamemodes/crmp_mvp.amx рядом с config.json.
4. Запусти сервер из этой папки.

Публичный Linux-бинарник под x86_64 нельзя запускать на ARM64-телефоне напрямую. На Termux нужен ARM64-бинарник либо Debian через proot и совместимая сборка.

## Важно о клиенте

Android-клиент из этого репозитория использует модифицированный RakNet/SA-MP handshake и собственные RPC. Этот MVP добавлен как серверная основа собственного проекта, но совместимость с текущим клиентом ещё не доказана. Не меняй адрес клиента на 127.0.0.1:7777 до отдельного теста handshake.
